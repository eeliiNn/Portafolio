# Elizabeth Portafolio

Contenido listo para un proyecto Next.js con App Router.

## Uso

1. Copia `app/`, `public/` y `package.json` a tu proyecto.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev`.

La imagen `public/profile-reference.jpg` se obtuvo del mockup compartido en la conversación.
Puedes reemplazarla por una foto original con el mismo nombre para obtener mejor calidad.
